Sub-processors

This page lists core service providers involved in providing Excel to Jira Importer & Updater.

Name Purpose Data involved
Atlassian Jira Cloud, Atlassian Forge hosting, app runtime, app storage, Marketplace installation, licensing and authentication context. Jira data available to the app, app configuration, import metadata, saved setups, import history, issue properties, user and site context.
Customer Jira site Customer-controlled Jira Cloud environment where project data, created issues, updated issues and issue properties are stored. Customer Jira project data, created or updated issue data and app issue properties controlled by the customer site.
Google Analytics Product analytics when configured for the production app, and public website measurement for product pages and campaign attribution. Sanitized usage events, operational labels, aggregate counts, browser-generated analytics client identifier and request metadata. The app is designed not to send full Excel files, workbook cell values, column names, Jira issue text, issue keys, project names, user names, email addresses, customer links or support messages.
Google Ads and Google tag services Consent-aware advertising measurement and campaign attribution on this public marketing website. Website visit and conversion measurement data controlled through the website consent banner and Google Consent Mode.

Changes

Material changes to sub-processors will be reflected on this page. Customers can contact Mederak Apps Service Desk with questions.

Analytics scope

Product analytics for the installed Forge app is limited to sanitized usage and reliability events. Website analytics for this public marketing website is separate from the Forge app runtime and does not process customer Excel files or Jira issue content from the installed app.
