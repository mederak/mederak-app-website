Latest Marketplace release

Version 1.31.2, published July 14, 2026

The latest Marketplace release makes it faster to bring spreadsheet data into Jira, keeps large-workbook review responsive and streamlines building Jira content from multiple source columns.

This release makes everyday spreadsheet-to-Jira work faster and more reliable.
  • Paste spreadsheet data directly into the reviewed import workflow.
  • Review large workbooks with responsive background processing and resumable progress.
  • Build and verify Jira content faster with row-by-row previews and instant column selection.

Recent highlights

Paste spreadsheet data

Copy tabular data from Excel Online, Google Sheets or another spreadsheet tool and take it through the same mapping, validation and review workflow as an uploaded file.

More reliable large-workbook review

Responsive background processing, resumable progress and smoother continuous table loading keep larger reviews moving.

Faster content building

Review Description output row by row and add source columns immediately in the Description and field value builders.

Contextual workbook help

Import Rescue appears when validation is blocked or the current import report contains failed rows, so users can reach support from the problem they are reviewing.

Start from a Jira issue

A Jira issue action can open the importer from the current issue and prepare the normal review-first workflow with that issue selected as the parent.

Safer review before import

Clearer repair guidance, cell-level ignore controls, better required Reporter handling and cleaner validation messages help users understand what needs attention before Jira is changed.

Marketplace release history

1.31.2July 14, 2026

Faster spreadsheet-to-Jira workflows

  • Paste spreadsheet data directly from Excel Online, Google Sheets or other spreadsheet tools and take it through the same mapping, validation and review workflow as uploaded files.
  • Review large workbooks more reliably with responsive background processing, resumable progress and smoother continuous table loading.
  • Build and verify Jira content faster with row-by-row Description previews and instant source-column selection in the Description and field value builders.
1.28.1July 12, 2026

Contextual workbook help

  • Added contextual workbook help when validation is blocked or a current import report contains failed rows.
  • Added a direct handoff to the Mederak Apps support form without automatically sending workbook content.
  • Preselected the relevant import stage when opening the contextual support form.
  • Removed the unused Diagnostic JSON export from validation review.
1.27.6July 10, 2026

Clearer completed-import report

  • Redesigned the completed-import report to make results, changed Jira issues and the next action easier to review.
  • Added a more considerate Marketplace review prompt after repeated successful imports, with a temporary Not now option and a direct support link.
  • Made it easier to review applied changes, download a workbook with Jira keys and return to import history.
1.27.5July 9, 2026

Start an import from a Jira issue

  • Added a Jira issue action that starts Excel to Jira Importer from the current issue.
  • Prepared the normal review-first import workflow with the current Jira issue selected as the parent.
  • Added a compact issue-view header explaining that Excel rows will be prepared as child Jira issues under the selected issue before review.
  • Moved parent context near the top of the issue-view import modal and removed repeated parent messages from the workflow.
  • Made the issue-view import modal easier to close and aligned the first loading screen with the app loading style.
  • Swapped and spaced Help and Close controls in the issue-view modal to reduce accidental clicks.
  • Updated the in-app "What's new" panel with a walkthrough of starting an import from a Jira issue.
  • Fixed Time tracking field mapping availability and validation copy so Jira configuration is not described as an importer limitation.
1.26.33July 1, 2026

Review, large workbook handling and release notes

  • Added clearer validation repair guidance on review and import report screens.
  • Added cell-level ignore and restore controls in Review changes.
  • Improved default Reporter handling and reduced duplicate validation messages.
  • Blocked mappings to Jira fields missing from current project metadata before import.
  • Aligned large-workbook upload and review limits to 10,000 data rows and 1,000,000 worksheet cells.
  • Added progress and time-left estimates while large workbooks are sent to review.
  • Improved review and import progress for longer 10,000-row workflows.
  • Added automatic suggestions for repeated-upload matching columns.
  • Fixed cleared values for existing Jira issues so intended clears are sent as updates.
  • Added a compact in-app "What's new" entry point and help-menu links to release notes, documentation and support.
1.25.3June 24, 2026

German interface support

  • Added German language support for the app interface.

Dark mode polish

  • Improved dark mode styling for workflow panels, dialogs, review tables and setup summaries.
  • Finished dark mode styling for recent workflow and saved setup history panels.
1.25.0June 23, 2026

Field value builder

  • Added a field value builder so users can combine multiple Excel columns into one mapped Jira field value with a custom separator.
  • Added optional shortening for built field values so long workbook text can fit Jira field limits before review and import.
1.24.1June 13, 2026

CSV/TSV import and export

  • Added CSV and TSV import for simple backlog tables, with separator and encoding controls before mapping.
  • Added CSV/TSV download with Jira issue keys after import, alongside the existing Excel download.
  • Fixed repeated-upload review so Summary values with equivalent spacing are no longer shown as changed.
1.23.5June 12, 2026

Review message cleanup

  • Fixed the change review table so repeated workbook validation messages are shown once per row instead of being duplicated when a larger review is processed in parts.
1.23.4June 12, 2026

Start screen and demo review fixes

  • Kept the start screen stable when customers move between the import and Fill Excel from Jira choices.
  • Fixed the demo review flow so browser-compatible row identity hashing no longer shows a crypto compatibility error.
